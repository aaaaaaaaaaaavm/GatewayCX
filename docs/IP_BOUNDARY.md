# Intellectual-property and publication boundary

This repository contains original project text and code written for the public GatewayCX record,
plus references to publicly available standards and programmes. It shall not contain confidential
customer information, unpublished vendor specifications, credentials, proprietary Avisys source
code or material copied from another project without a compatible licence.

GatewayCX is described as work initiated at Avisys Services. That description does not by itself
settle legal ownership, trademark rights or authority to commit future company or partner
material. Those questions require written organisational decisions before commercial release,
partner-data publication or transfer into an Avisys-owned organisation.

Public discussion with a supplier does not create a partnership. A vendor appears in the record
only as a sourced candidate implementation unless a written relationship permits stronger
language.
