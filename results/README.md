# Results

`baseline.json` is generated from every `scenarios/S*.json` file by:

```bash
python -m gatewaycx.cli run-all
```

The file is committed so a change to code or assumptions produces a visible diff. It contains no
generation timestamp, which makes an unchanged run byte-for-byte reproducible.

Additional bounded studies have separate records:

- `S004_native_https.json` is a dated socket measurement and is not regenerated as a deterministic
  CI artifact.
- `S005_disruption.json` is a deterministic IP/DTN semantic replay generated by
  `python -m gatewaycx.disruption`.
- `S006_capacity_envelope.json` is a deterministic derivation generated by
  `python -m gatewaycx.capacity`.
- `S007_service_placement.json` is a deterministic exhaustive placement model generated by
  `python -m gatewaycx.placement`.
- `S009_admission.json` is a deterministic contact-capacity admission comparison generated by
  `python -m gatewaycx.admission`.
- `S010_handover.json` is a deterministic RF/optical handover replay generated by
  `python -m gatewaycx.handover`.
- `S011_update_delivery.json` is a deterministic chunk-transfer and A/B activation model generated
  by `python -m gatewaycx.update_delivery`.
- `S012_prepositioning.json` is a deterministic forecast/allocator comparison generated by
  `python -m gatewaycx.preposition`.
- `S013_black_start.json` is a deterministic dependency and single-fault record generated by
  `python -m gatewaycx.black_start`.
- `S014_diagnostic_trace.json` is a deterministic GX-O1 trace generated and validated by
  `python -m gatewaycx.diagnostics`.
- `S015_integrated_replay.json` composes warm bearer handover, durable delivery and GX-O1 events;
  it is generated by `python -m gatewaycx.integrated_replay`.
- `S016_adapter_probe.json` exercises the GX-A1 profile-backed runtime seam across the optical and
  RF reference profiles; it is generated by `python -m gatewaycx.adapter_probe`.
- `S017_durable_restart.json` exercises a payload-blind SQLite traffic ledger across separate seed
  and recovery processes; it is generated by `python -m gatewaycx.durable_restart`.
- `S018_adapter_transport.json` exercises the GX-A1 loopback JSONL process binding and restart;
  it is generated by `python -m gatewaycx.adapter_transport_probe`.
- `S019_authenticated_transport.json` exercises HMAC-authenticated GX-A1 requests, signed
  responses and durable replay rejection; it is generated by
  `python -m gatewaycx.authenticated_transport_probe`.
- `S020_abrupt_restart.json` kills SQLite writer processes before commit and after commit but
  before close; it is generated by `python -m gatewaycx.abrupt_restart`.

No result is evidence of a flight network or hardware qualification.
