# Scope

## In scope

- Native terrestrial Internet compatibility across an Earth–Moon network
- Lunar surface and orbital access networks
- RF, optical and hybrid cislunar backbone bearers
- IPv6 operation across continuous paths
- Delay-tolerant and store-and-forward operation across disruption
- Naming, service discovery, identity, trust and time services
- Lunar and orbital data centres, caching and data replication
- Application behaviour under delay and partition
- Traffic classes, safety priority, capacity allocation and observability
- Multi-provider interfaces, governance and service operations
- Executable models, emulation, reference software and interoperability tests

## Not yet in scope

- Detailed spacecraft or optical-terminal hardware design
- A flight-qualified terminal or ground station
- A final lunar constellation
- Spectrum filings or regulatory approval
- A production ISP, cloud service or billing product
- Claims of measured performance
- Vendor selection

These exclusions describe the current baseline, not the full roadmap.

## Non-goals

- Replacing the terrestrial Internet with a new application ecosystem
- Making every legacy real-time application perform well without regional deployment
- Hiding physical latency with misleading figures
- Treating the Deep Space Network as unlimited commercial infrastructure
- Locking the architecture to a single terminal, constellation or operator
